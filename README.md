## 覆盖的消息类型

文本 / 语音 / 图片 / 链接 / 文件 / 位置 / 名片 / 引用消息 / 合并转发

**关键原则：不许只捞文字。** 只分析文字、跳过语音和附件就下结论，是最常见的错误——结论会失真。

## 三条硬规矩

### 1. 语音必须转写

跳过语音等于漏掉一半对话。语音要转成文字再一起分析。

### 2. 群聊要查产量

群里说「每天三百条」，你只导出五十条就是漏了。要有产量校验，防止静默丢数据。

### 3. 不许只查一个群

「只查了一个群就说没有这件事」是典型误判。结论里要能说清翻了哪些会话、哪类消息。
